# Escalator fixed-mesh topology repair

PASS: primary delivery has 65,394 triangles, down from 65,408. Removed 11 exact-zero triangles and three separately reviewed analytic-line precision remnants. Source reopen, fresh generation and canonical native import report zero degenerates. All 200 editable objects remain; the 60 rigid animation clips are preserved.

The original source is Blender 4.0.2. An isolated official macOS ARM64 binary was checksum/signature verified. Its unchanged-source export is byte-identical to the original GLB. Blender 5.1.2 changes 1,086 oriented surface triangles even without editing the source, so that toolchain was rejected for this asset. The existing application and GUI scene were untouched. See [matching toolchain proof](matching-toolchain.json) and the [official checksums](https://download.blender.org/release/Blender4.0/blender-4.0.2.sha256).

Cleanup is additive on seven reviewed fixed panels. Canonical index changes affect only GUARD_R, SKIRT_L, TRUSS_Bottom, TRUSS_L and TRUSS_R. Every instance of a changed mesh and all its ancestors are checked for animation. The opt-in rigid-container mode rejects skins, morphs, unsupported channels, animated targets and animated ancestors. Default animated-asset rejection remains in place. Source snapshots cover all 60 active Object actions, 420 curves, 466,354 keyframes, interpolation/handles, assignments and frame/FPS settings through export/save/reopen. NLA, drivers, sampled curves and action modifiers require separate review.

Canonical positions, normals, materials, bounds, nodes and all animation descriptor/accessor payload bytes are unchanged. The native oracle also matches all 60 clips/120 tracks with zero time/value drift. A real keyframe mutation changes the source snapshot and restoring it restores the snapshot. Actual Three.js AnimationMixer playback samples every clip at five times (300 samples), verifies movement, finite/unit transforms and unchanged repaired static matrices. Existing candidate motion/contact evidence is reused only after original vertex attributes, retained ordered indices, transforms, materials and exact tracks are checked. The previous mechanism NEEDS REVIEW status remains.

Three positive-area Float64 remnants lie on the source's mathematical straight incline. Their nominal altitude is below 1e-14 m; maximum exported perpendicular error is 9.982e-10 m. Original Float32 vertex rounding is independently bounded against the generator's double-precision profile. The explicit 1.1e-9 m calibration is limited to TRUSS_L/TRUSS_R. Native export validates each candidate against that source profile before filtering. A source edit that invalidates the calibration is refused. One smaller remnant survives the native triangulator and is removed by this checked export stage. Canonical reconstruction removes the three approved remnants while keeping original attributes. This is an asset-specific analytic proof, not a general tiny-face deletion rule. Defaults and real 1 nm/10 um counterexamples remain protected; a separate fixture preserves an identical tiny face on an unreviewed node.

A saved BELT_Seam edit changes local width to 92% and shared material roughness to 0.77. An unchanged saved-source control and the edited copy are exported with the same toolchain: exactly one geometry part changes, 137 siblings match, all 60 animation payloads match and canonical files retain their hashes. The old source-edit artifacts remain historical; source-edit-current contains the current probe. An initial stale Object reference after reopening was caught and corrected by retaining its name before reopening.
