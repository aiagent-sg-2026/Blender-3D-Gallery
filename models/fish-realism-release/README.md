## Reproduction

Run Blender 5.1.2 in background mode with `--python-exit-code 1 --python models/fish-realism-release/export.py -- SLUG` for each manifest entry, then `python3 models/fish-realism-release/register.py`. Export never saves changes to the source. Delivery copies flatten temporary skinned mesh parenting, repair n-gon cap UVs and use WebP textures at quality 95. Morph meshes retain their shape keys. Each export receipt records source and output SHA-256.

Run `npm run build`, Blender with `--python-exit-code 1 --python models/fish-realism-release/verify.py`, and `node models/fish-realism-release/test-browser.mjs`. Set `FISH_LIVE_URL` to the deployed gallery URL (with trailing slash) to test the actual published catalog. Browser checks use no model substitution: response bytes must match the released GLB. They check visible swim deformation, stable pause, disposal, console errors and overflow in Chromium and WebKit at desktop and mobile viewport sizes. These are emulated viewports, not physical-device performance measurements.

The accepted ray is an explicit quality-preserving exception to the proposed 5 MiB / 100k triangle candidate budget: approximately 12.4 MiB / 113k triangles including its morph targets and surface detail. It remains lazy-loaded on opening the viewer. The other delivery models are under 5 MiB each. Betta retains the original creator's small loop endpoint difference; the verification threshold records this rather than claiming a perfectly seamless original clip.

Reference photos are not embedded. The Betta source and CC BY 4.0 links appear in the viewer, together with creator credit and modifications. Per-model metadata retains the artistic/identification limits. A previous archive-only acceptance receipt describes its historical release; this manifest describes the later live promotion.

WebKit receipts separately retain existing native-select CSP events. Screenshot-time `style-src-elem` events are accepted only inside the capture interval: the installed Playwright screenshot preparation injects `body {}` for animation synchronization, which production CSP blocks. Neither the application CSP nor the validator was weakened. Other page/console errors or CSP events fail the browser check.

Incremental browser runs can set `FISH_SLUGS=slug-a,slug-b` and `FISH_BATCH=batch-02`; full runs default to every manifest entry. New batches retain earlier artifact hashes and their existing browser receipts.

To stage a future batch from the authoring checkout, run `uv run --with pillow python models/fish-realism-release/promote.py --from-root /path/to/authoring-checkout SLUG...` in the isolated release checkout. This copies only sealed, hash-verified original artwork and prepares metadata/posters; it still requires export, catalog registration, artifact/build/browser verification and a verified deployment before claiming online availability.

Older first/batch-02 receipts use `native_select_csp_warnings` for the combined known CSP console-message count. Their event lists distinguish native-select and screenshot-preparation events. Batch 03 onward names those counts separately and checks errors again after capture and viewer disposal.
